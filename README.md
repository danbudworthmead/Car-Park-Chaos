# Car Park Chaos

## Overview

Car Park Chaos is a multiplayer physics-based party game where players control cars in a chaotic battle to secure parking spaces. The game is played in rounds, with the goal of each round being to find a parking space. The player who fails to secure a space is knocked out, and the last player remaining after multiple rounds is declared the winner.

## Player

Players will navigate and control cars within the game.

## Matches

Each match consists of multiple rounds. The main game mode involves a series of rounds, with one player being eliminated in each round until only one remains.

## Rounds

In each round, there will be n-1 parking spaces, where n is the number of players. For example, if there are 4 players, there will be 3 parking spaces available. The challenge is to find a parking space before the others.

## Objectives

The primary objective in each round is to locate and secure a parking space within the allotted time.

## Lose Scenario

A player loses the round if they are unable to find a parking space within the time limit.

## Car Park

The car park is randomly generated, with all spaces initially filled with random cars, creating a dynamic and challenging environment.

## Customization

Players have the option to choose from a variety of cars, which can be unlocked by winning matches. Additionally, each player's Steam name will be displayed on their car's number plate, adding a personalized touch to the game.

## Design

The game features low-poly design assets to create a visually appealing and accessible aesthetic. An early art test has been conducted to showcase the intended look and feel of the car models.
